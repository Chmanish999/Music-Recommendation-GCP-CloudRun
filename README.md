# 🎵 Music Genre Recommendation App

## Google Cloud Run Deployment

This Music Genre Recommendation Flask App is containerized using Docker and deployed on Google Cloud Run.

Live GCP App:
https://music-recommendation-gcp-cloudrun-488043604164.asia-south1.run.app

## 🚀 Features
- User-friendly web interface
- ML model using Decision Tree
- Real-time prediction using Flask

## 🧠 Input
- Age
- Gender

## 🎯 Output
- Recommended Music Genre

## 🛠 Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- Joblib
- HTML/CSS
